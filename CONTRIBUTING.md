# Contribution

Le dépôt n’est pas encore public et reste non licencié. Toute contribution doit :

- respecter `AGENTS.md` et les ADR ;
- être liée à une étape ou une issue explicite ;
- inclure les tests du comportement modifié ;
- ne pas ajouter de dépendance sans justification ;
- ne pas incorporer de ressource ou code propriétaire ;
- utiliser des commits conventionnels (`feat:`, `fix:`, `test:`, `docs:`, `build:`).

Avant soumission : `./scripts/verify.sh` et mise à jour de la documentation de comportement.
