# Backlog après MVP

Ces éléments ne doivent pas entrer dans les trois étapes actuelles sans décision explicite :

- RTP-MIDI, OSC et Ableton Link.
- Bluetooth MIDI.
- CV via interface DC-couplée et calibration.
- USB audio multicanal direct.
- Microtonalité, Scala/KBM, MPE et MIDI 2.0.
- Éditeur complet de gammes et banques étendues.
- Synchronisation cloud des presets.
- Plugin desktop ou version multiplateforme.
- Automatisation avancée des paramètres DSP.
- Export/import de sessions et partage communautaire.
