# Preuves de validation

Déposer ici uniquement des éléments légers et non sensibles : rapports Markdown,
exports MIDI textuels anonymisés, mesures de latence CSV et captures de diagnostics.

Ne pas versionner :

- APK/AAB, caches ou dumps mémoire ;
- numéros de série, identifiants personnels ou chemins utilisateurs ;
- clés de signature, tokens ou configurations de compte ;
- copies du guide, graphismes ou ressources du produit de référence ;
- enregistrements audio dont les droits ne sont pas établis.

Les médias volumineux doivent être stockés comme artefacts CI ou dans un stockage de test
séparé, avec un lien et une empreinte dans le rapport matériel.
