# Journaux d’implémentation Codex

Ce répertoire reçoit le plan et le compte rendu de chaque grande étape autonome.
Il n’est pas destiné aux micro-tickets.

## Convention

- `STAGE_1_PLAN.md` — instrument intervallique MIDI.
- `STAGE_2_PLAN.md` — Tone Row et transport.
- `STAGE_3_PLAN.md` — audio, UX et durcissement.
- `HARDWARE_REPORT_2026-08-21.md` — réception tablette et campagne A/B initiales.
- `HARDWARE_REPORT_2026-08-22.md` — réception articulation/strummer du build courant ;
  écoute anti-saturation explicitement ouverte.

Chaque fichier est créé à partir de `STAGE_PLAN_TEMPLATE.md`, puis maintenu comme
journal factuel de l’étape. Il doit distinguer les validations hôte, Android, MIDI USB
et audio matériel. Un test non exécuté n’est jamais présenté comme réussi.
